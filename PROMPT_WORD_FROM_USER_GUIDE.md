# Prompt untuk Membuat Dokumen Word dari User Guide

Salin seluruh prompt di bawah ini ke GPT, lalu lampirkan atau tempelkan isi file `USER_GUIDE.md` setelah prompt.

---

Anda adalah document specialist. Ubah isi User Guide Toyota CCR Dashboard yang saya berikan menjadi dokumen Microsoft Word (`.docx`) berbahasa Indonesia yang profesional, ringkas, dan mudah dibaca oleh pengguna operasional.

Tujuan dokumen adalah memberikan gambaran umum aplikasi sekaligus petunjuk praktis penggunaan fitur utama. Pertahankan urutan langkah penggunaan yang ada pada sumber, tetapi jangan menambahkan langkah teknis yang tidak didukung sumber.

Ikuti ketentuan berikut:

1. Pertahankan seluruh fakta dan nama fitur dari sumber. Jangan menambahkan fitur, hak akses, aturan bisnis, atau klaim yang tidak tertulis di sumber.
2. Gunakan judul dokumen: **User Guide Toyota CCR Dashboard**.
3. Buat halaman cover yang berisi:
   - Judul dokumen
   - Subjudul: PPIC & Warehouse
   - Kolom informasi: Versi Dokumen, Tanggal Revisi, dan Disusun Oleh. Isi dengan placeholder yang dapat diedit.
4. Buat daftar isi otomatis setelah cover.
5. Susun isi dengan heading bernomor mengikuti struktur sumber: Tujuan Aplikasi, Login, Home, Asakai Board, Input Data, Production Achievement, Planning, Users, dan Catatan Penggunaan.
6. Gunakan gaya visual profesional dan sederhana:
   - Font Aptos atau Calibri.
   - Heading utama berwarna biru tua.
   - Isi teks ukuran 10,5 atau 11 pt.
   - Spasi antar paragraf cukup lega.
   - Gunakan bullet list hanya ketika membantu keterbacaan.
7. Pertahankan subbagian **Fitur yang tersedia**, **Informasi yang tersedia**, dan **Cara menggunakan** pada setiap halaman agar pembaca mengetahui fungsi menu serta langkah dasarnya.
8. Untuk tiga jenis input Excel (Stock, Shipment, dan LSR), tampilkan informasi sheet dan data utama dengan tabel sederhana agar mudah dipahami.
9. Tambahkan kotak catatan berwarna lembut untuk informasi penting, terutama pada proses import, konflik data, dan akses Admin.
10. Jangan membuat bagian istilah penting/glossary.
11. Jangan menambahkan screenshot maupun placeholder screenshot. Screenshot akan dimasukkan manual di kemudian hari.
12. Tambahkan header berisi `Toyota CCR Dashboard` dan footer berisi nomor halaman.
13. Hasil akhir harus berupa file `.docx` yang dapat diedit, bukan PDF.
